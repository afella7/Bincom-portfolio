# Personal Portfolio Website

A responsive personal portfolio website built from scratch using HTML, CSS, and JavaScript as part of the Bincom Developer Assessment.

## Features

- Responsive design for desktop, tablet, and mobile
- Interactive mobile navigation
- About Me, Skills, Projects, Experience, and Education sections
- Photo gallery with an interactive JavaScript lightbox
- Contact links to email, LinkedIn, and GitHub

## Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
- Vanilla JavaScript

## Getting Started

1. Clone the repository:
   `git clone https://github.com/afella7/bincom-portfolio.git`
2. Open the project folder.
3. Open `index.html` in your browser.

No additional dependencies or installation required.
